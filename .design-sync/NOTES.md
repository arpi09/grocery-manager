# design-sync notes

- **Shape: styles/tokens only (off-script).** `home-pantry` is a SvelteKit app — no
  publishable component library `dist/` and no Storybook — so the standard converter
  (React component bundle) does not apply. We ship only the brand token layer. Chosen by
  Arvid on 2026-07-04 ("Tokens/styles only").
- **Token sources** (both generated by `scripts/generate-brand-css.mts`, do not hand-edit
  the sources): `src/lib/design/brand-colors.generated.css`,
  `src/lib/design/brand-tokens.generated.css`. On re-sync, re-copy these into
  `ds-bundle/tokens/{colors,typography}.css` verbatim.
- **Dark mode** is gated on `html[data-theme='dark']` (matches app.html).
- **`DM Sans` is a Google Font** loaded via `src/app.html` (external). It is **not embedded**
  in the bundle — Claude Design's CSP blocks external font hosts. The `--font` stack falls
  back to `system-ui`. To improve typographic fidelity later, embed DM Sans (OFL, weights
  400/500/600/700) as `ds-bundle/fonts/*.woff2` with an `@font-face` `@import`ed from
  `styles.css`.
- **Bundle is built in the session scratchpad**, not committed to the repo (it's an upload
  artifact, not source). Only `.design-sync/` is committed.
- **No `_ds_sync.json` anchor** is written (off-script, nothing to verify). Re-sync simply
  rebuilds the token bundle from the two sources above and re-uploads.
- **Project pin (2026-07-04):** on re-sync no writable Claude Design project existed (the prior
  sync had never pinned a `projectId`, and its project was gone), so a fresh project **"Skaffu
  Design System"** was created — `projectId` `f06626f0-ce11-4687-bbf5-03ac70c38e44`, now pinned
  in `config.json`. Future re-syncs will target it automatically instead of creating duplicates.
- **Uploaded layout:** `styles.css` (@imports the two token files — this is the closure designs
  receive), `README.md` (= conventions header), `tokens/{colors,typography}.css`, and two
  Foundations preview cards `components/foundations/{colors,typography}/*.html` (`@dsCard`-marked).
